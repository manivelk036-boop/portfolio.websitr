# 📘 Portfolio Website Documentation

## 1. Project Overview

This project is a personal portfolio website created to showcase my
profile, technical skills, projects, education, certificates, learning
journey, and contact information.

The website is designed to be responsive and accessible on mobile,
tablet, and desktop devices.

## 2. Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- Vercel

## 3. Website Sections

The portfolio contains:

- Home
- About Me
- Skills
- Services
- Projects
- Education
- Certificates
- Learning Journey
- Testimonials
- Portfolio Statistics
- Contact

## 4. Main Features

### Dark / Light Mode

Users can switch between dark and light themes.

### Project Filtering

Projects can be filtered using:

- All
- Spring Boot
- Web

### Loading Screen

A loading screen is displayed while the portfolio is loading.

### Responsive Design

The website adapts to different screen sizes including mobile,
tablet, and desktop.

### Resume Download

Users can download my resume from the portfolio.

### Social Links

The portfolio provides links to GitHub and LinkedIn.

## 5. Projects

### Student Complaint Management System
